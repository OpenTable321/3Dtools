Мульти-просмотр моделей

Загружайте несколько 3D-моделей сразу и инспектируйте их рядом в одном вьюпорте. Перетащите смесь файлов STL, OBJ, GLB, PLY и 3MF — или один файл с несколькими объектами — и каждый станет вкладкой, которую можно переключать и редактировать независимо.

Всё работает локально в вашем браузере через WebGL. Файл никогда не загружается на сервер, просмотр работает с файлами в десятки мегабайт. Если файл не парсится, вы получите понятное сообщение об ошибке вместо пустого экрана.

Открыть: Мульти-просмотр моделей Работает локально в вашем браузере — файл не покидает ваше устройство.

Как просмотреть файл STL,

  1. Нажмите Открыть: Мульти-просмотр моделей выше (или откройте студию 3DTools).
  2. Перетащите файл во вьюпорт или нажмите Открыть файл(ы).
  3. Вращайте левой кнопкой мыши, масштабируйте колесом, двигайте правой кнопкой.
  4. Переключайте режимы отображения (сплошной, каркас, рентген, нормали, вершины) на вкладке Вид.
  5. Измеряйте, режьте или анализируйте модель на вкладке Анализ — или конвертируйте на вкладке Конвертация.

Мульти-просмотр полезен для сравнения ревизий, проверки стыковки деталей или организации многокомпонентной печати. Каждую загруженную модель можно трансформировать, анализировать и экспортировать по отдельности или объединить в один меш одним кликом.

Приватность по архитектуре

У этого просмотра вообще нет эндпоинта загрузки. Файл читается через FileReader браузера, парсится в JavaScript и рендерится через WebGL — всё на вашей машине. После загрузки работает и офлайн. Подробности — в политике конфиденциальности.

Часто задаваемые вопросы

Сколько моделей можно загрузить?

Жёсткого лимита нет — зависит от памяти устройства. Каждая модель — GPU-буфер; типичные рабочие станции справляются с десятками средних мешей.

Можно ли загружать разные форматы вместе?

Да. Смешивайте STL, OBJ, GLB, PLY и 3MF свободно; каждый файл парсится своим загрузчиком.

Можно ли объединить модели в один файл?

Да. «Объединить все загруженные модели» создаёт один меш, который можно экспортировать в любом поддерживаемом формате.

Можно ли временно скрыть модель?

Да — у моделей есть переключатели видимости, а правый клик по вкладке удаляет модель из сцены.
